# Sécurité et confidentialité — v0

Statut : **proposé**. Aucune conformité n'est affirmée ; validation juridique compétente requise avant pilote.

- Données de mineurs : minimisation (pseudonyme élève, pas de photo de visage, pas de biométrie), pas d'entraînement de modèles.
- Cadres à vérifier sur sources officielles : Maroc, loi 09-08 et CNDP (déclaration/autorisation, transferts hors Maroc) ;
  RGPD si hébergement ou clients UE. Rôles école (responsable de traitement) / AlphaStudyFlex (sous-traitant) à contractualiser.
- Menaces prioritaires : fuite entre écoles, exposition des corrigés, injection de prompt via documents ou réponses élèves,
  escalade de rôle, références directes à des objets interdits, fuite de données dans les logs.
- Productions des élèves (audio, photos) : accès, conservation et suppression explicites, à définir avec l'école.
- Détail (matrice de permissions, modèle de menaces, durées de conservation) : jalon J2/J6.
